# 余烬营地 · Ember Camp Online v0.2

这是一个**可以真正实时联机**的 3D 低多边形合作生存建造原型，支持最多四名玩家同时加入同一个房间。

- 原生 WebGL 1 渲染 3D 森林、人物、怪物、营地、树木、矿石、建材。
- Node.js 自带 HTTP + WebSocket RFC6455 基础服务器，无需 `npm install`。
- 服务器权威计算移动、采集、建造、怪物 AI、伤害和昼夜。
- 电脑 WASD 和手机触屏操作；同一公网服务支持跨设备联机。
- 昼夜循环、夜间怪物攻城、坚守三夜通关、房间码、30 秒断线重连。

> 注意：这是垂直切片原型，**不是**完整游戏：暂无账号/永久存档、复杂物理、真正的怪物寻路、成熟动画、持久化世界。原计划使用 Three.js + Colyseus，当前首版为了零依赖、便于运行，使用原生 WebGL + Node.js 内置网络能力。联机协议和游戏逻辑已模块化，为后续迁移留出了空间。

## 一、电脑本地运行

1. 安装 Node.js **22 或更新版本**（https://nodejs.org/）。
2. 解压项目，打开命令行进入 `ember-camp-mvp` 文件夹。
3. **Windows 可直接双击 `start-windows.bat`**；其他系统运行：

   ```bash
   npm start
   ```

4. 浏览器访问 **http://localhost:3000**。
5. 点击 **创建营地**，即可单人体验。要测试联机，用另一个浏览器标签页输入房间码加入。

无需额外安装依赖，**不需要先执行 npm install**。

## 二、电脑 + 手机同一 Wi-Fi 联机

1. 电脑上运行 `npm start`。
2. 查找电脑的局域网 IPv4 地址（Windows 运行 `ipconfig`，寻找 `192.168.x.x` 等）。
3. 手机和电脑连接同一 Wi-Fi，在手机浏览器访问：`http://电脑的IP:3000`。
4. 电脑创建营地，手机输入房间码加入。
5. 如果手机无法打开网页，请允许 Windows 防火墙中该 Node.js 程序的私人网络访问，并确认路由器未开启客户端隔离。

## 三、跨互联网联机（现已准备好 Render 部署）

可通过 Render 免费 Web Service 部署（参考 `DEPLOY-RENDER.md`）。服务器支持 `PORT`、自动使用 HTTPS/WSS、六位邀请码和手机系统分享链接。**免费服务休眠、重启或重新部署会清空内存房间**，仅适合小范围好友试玩；尚无永久存档和成熟的防滥用系统。

## 四、操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧方向键 |
| 采集 | E | 采集按钮（靠近资源） |
| 攻击 | 空格 | 攻击按钮（自动瞄准最近敌人） |
| 选择木墙 | 1 | 木墙按钮 |
| 选择篝火 | 2 | 篝火按钮 |
| 建造 | B | 建造按钮（建在角色朝向前方） |
| 食用浆果恢复 25 HP | H | 食用按钮 |

初始获得 8 木头 + 4 石头。建造木墙消耗 4 木头；篝火消耗 5 木头和 3 石头。每次采集会得到 2 个相应资源（树木或矿石），或 2 颗浆果。怪物被击败奖励 1 木头。

## 五、验证

```bash
npm test
```

测试覆盖网页服务、双玩家真实 WebSocket 联机、建造同步与扣费、移动同步，以及对客户端伪造伤害消息的基础抗性。可在本机开多个浏览器测试不同设备与网络情况。
