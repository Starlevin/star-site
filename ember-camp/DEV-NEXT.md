# 余烬营地 · 下一轮开发任务（Agent 可直接阅读）

## 当前已实现（v0.1）
- 零 npm 依赖的 Node.js HTTP + WebSocket 服务，房间验证码，最多 4 人，30 秒内重连。
- WebGL 3D 低多边形森林、营地、资源、怪物、建材、角色。
- WASD / 手机方向键移动；采集、攻击、食用浆果、选择并放置木墙/篝火。
- 服务器实时判定物品、建造消耗、战斗、敌人和昼夜循环。
- 自动化双玩家房间同步验证与 WebGL 展示验证（浏览器展示检查利用注入的模拟快照）。

## v0.2 优先级 P0
1. 给 WebGL 场景增加真正的鼠标/触屏点选放置，服务端仍需检查碰撞和消耗。
2. 角色攻击方向、受击反馈、跳血数字、采集音效、简易动画。
3. 怪物出现时添加小地图标记和屏幕方向箭头。
4. 摄像机改为可旋转缩放（移动端双指缩放）；保证 UI 不遮挡。
5. 更多自动化模拟测试：资源争抢、4 人满房、短暂掉线、恶意输入边界、3 个夜晚与胜负结算。

## v0.3 优先级 P1
1. 用 Colyseus 取代自写 WebSocket 房间协议（保留服务器权威规则）。
2. 世界块分区 / AOI，同步差量状态，不再广播全地图资源快照。
3. 用 Three.js 取代轻量渲染层，统一阴影、动画与模型加载，保持上层网络协议与实体模型独立。
4. 碰撞从 AABB 升级为建造导航障碍，怪物避免卡在墙后。
5. 服务器容器化部署与 wss 反向代理；为 4 人好友局设计小型压测。

## v0.4 优先级 P2
1. 持久化存档、玩家账号/访客身份、房主权限。
2. 工作台、武器耐久、更多怪物与精英 Boss、资源刷新。
3. 智能采集、修墙、怪物掉落、科技树与多人分工。

## 注意
- 当前原型服务属于受信任小圈子测试，**不要直接作为公开线上正式运营服务器**。
- 服务器无持久数据库，进程停止后房间和进度全部丢失。
- 素材全部由代码生成，未使用第三方音乐、模型或受版权保护的游戏素材。
- 原型技术栈不是以前计划中的 Three.js / Colyseus，二者为可控的下一阶段迁移目标。
